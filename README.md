> 三大报表进行系统性拆解，回答一个问题：**谁的基本面最健康，各自的商业模式如何

## 1. 项目背景与业务问题

互联网平台的商业模式差异巨大：游戏公司靠高毛利的内容，外卖平台靠高周转的履约网络，
短视频公司处在"烧钱换增长"到"盈利兑现"的转型期。本项目从经营分析视角出发，
通过财务指标拆解回答四组业务问题：

| 主题 | 核心问题 | 对应脚本 |
|---|---|---|
| 成长性 | 谁还在增长，谁已失速？增长在加速还是减速？ | `01_收入与增长分析.sql` |
| 盈利性 | 毛利率差异多大？谁先扭亏？ROE 靠什么驱动？ | `02 / 03 / 04` |
| 现金质量 | 利润是真金白银还是纸面富贵？SBC 侵蚀多严重？ | `05_现金流质量分析.sql` |
| 安全性 | 资产负债表稳不稳？商誉减值风险多大？ | `06_偿债能力与资产质量.sql` |
| 业务结构 | 收入结构如何迁移？谁是第二增长曲线？ | `07_分业务收入结构.sql` |
| 综合结论 | 四维打分，谁的基本面最健康？ | `08_综合评分卡.sql` |

## 2. 数据说明

- **来源**：iFinD（同花顺）金融数据终端，上市公司公开披露财报
- **范围**：5 家公司 × FY2021–FY2025 三大报表（25 行/表）+ FY2023–FY2025 分业务收入（57 行）
- **清洗**：`scripts/etl_clean.py` 将原始导出整合为 5 张分析就绪表，详见 `docs/数据字典.md`
- **数据治理要点**：
  - 腾讯研发费用未单独披露 → 保留 `NULL` 并以 `NULLIF` 处理，**不用 0 填充**（0 与"未披露"业务含义不同）
  - 快手无存货、部分分部毛利缺失 → 保留 `NULL`
  - 净利润为负时，净现比（CFO/净利润）方向会反转 → 用 `CASE` 结合符号判断，不直接读数值

## 4. 快速开始

## 6. 核心发现（基于 FY2025 数据）

1. **网易、腾讯是"利润率驱动型"**：净利率约 30%，ROE 分别约 20%、18%，靠高毛利内容业务赚钱；
2. **美团是"周转驱动型"**：总资产周转率约 1.0 为五家最高，但 2025 年因外卖行业补贴大战
   费用率骤升、净利润转负，是"高收入低利润"商业模式脆弱性的典型案例；
3. **B 站 2025 年首次年度盈利**，验证"降本增效 + 广告变现"逻辑，净现比高达 6 说明利润含金量极高；
4. **快手五年收入 CAGR 约 12%**，且费用率持续摊薄，经营杠杆兑现最明显；
5. 综合评分卡（成长 30% / 盈利 30% / 现金 20% / 安全 20%）：腾讯、网易居前，美团垫底——
   增长最快但盈利与现金流承压。

> 以上结论由 `sql/analysis/08_综合评分卡.sql` 一键复现。
