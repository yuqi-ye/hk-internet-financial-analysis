# 数据字典

> 数据来源：iFinD（同花顺）金融数据终端，报表区间 FY2021–FY2025（分业务数据 FY2023–FY2025）。
> **单位说明**：原始接口返回的金额为统一计价单位（下同"单位"），所有比率、增速、占比指标均与单位无关；涉及绝对金额时统一除以 1e8 记为"亿单位"。项目用于分析方法演示，横向、纵向比较口径一致。

## companies（公司维度表，5 行）

| 字段 | 类型 | 说明 |
|---|---|---|
| ticker | VARCHAR(10) | 证券代码（主键），如 0700.HK |
| company_name | VARCHAR(50) | 公司中文名 |
| company_name_en | VARCHAR(50) | 公司英文名 |
| main_business | VARCHAR(100) | 主营业务描述 |
| market | VARCHAR(10) | 上市市场（HK） |
| listing_year | INT | 上市年份 |

## income_statement（利润表，5 公司 × 5 年 = 25 行）

| 字段 | 说明 | 备注 |
|---|---|---|
| ticker, fiscal_year | 联合主键 | |
| revenue | 营业收入 | |
| cost_of_revenue | 营业成本 | |
| gross_profit | 毛利润 | = revenue − cost_of_revenue |
| selling_expense | 销售及营销费用 | |
| admin_expense | 管理费用 | |
| rd_expense | 研发费用 | **腾讯为 NULL**（数据源未单独披露），分析时用 NULLIF 处理，不可填 0 |
| operating_profit | 经营利润 | |
| pretax_profit / income_tax / net_profit | 税前利润 / 所得税 / 净利润 | |
| net_profit_attributable | 归母净利润 | 本项目盈利指标统一用归母口径 |

## balance_sheet（资产负债表，25 行，年末时点）

| 字段 | 说明 | 备注 |
|---|---|---|
| total_assets / total_liabilities / total_equity | 总资产 / 总负债 / 股东权益 | |
| current_assets / current_liabilities | 流动资产 / 流动负债 | |
| cash_and_short_invest | 现金及短期投资 | |
| accounts_receivable / inventory | 应收账款 / 存货 | 快手等无存货为 NULL |
| goodwill / intangible_assets | 商誉 / 无形资产 | 用于减值风险评估 |
| deferred_revenue_current | 合同负债/递延收入 | 游戏/会员业务的先行指标 |

## cash_flow（现金流量表，25 行）

| 字段 | 说明 |
|---|---|
| cfo / cfi / cff | 经营 / 投资 / 筹资活动现金流净额 |
| capex | 资本开支（购建固定资产、无形资产） |
| depreciation_amortization | 折旧摊销 |
| stock_based_comp | 股权激励费用（SBC） |
| fcf | 自由现金流 = cfo − capex |

## business_segmentation（分业务收入，57 行，FY2023–2025）

| 字段 | 说明 |
|---|---|
| ticker, fiscal_year, segment_name | 联合唯一键 |
| segment_revenue | 分部收入 |
| segment_gross_profit | 分部毛利（部分缺失，为 NULL） |
